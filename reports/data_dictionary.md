# Data Dictionary

**E-Commerce Revenue & Customer Analytics**

This document describes every table and column produced by the pipeline. All
data is **synthetic**, generated by `scripts/generate_data.py` with a fixed
random seed (42) for full reproducibility. No real customer or transaction
data is used anywhere in this project.

Two layers of tables exist:

- **Raw tables** (`data/raw/`) — output of `generate_data.py`, includes
  intentionally injected data quality issues.
- **Cleaned / enriched tables** (`data/processed/`) — output of
  `clean_data.py` and `feature_engineering.py`. These are the tables used by
  the notebooks, SQL queries, and dashboard.

## rfm_customer_segments

One row per customer with at least one valid (non-cancelled) order. Output of `scripts/rfm_segmentation.py`.

| Column | Type | Description | Example | Business Meaning |
|---|---|---|---|---|
| customer_id | integer | Customer identifier (FK) | 10234 | Joins to `customers` |
| customer_name, city, state | various | Copied from `customers` for convenience | — | Display |
| recency | integer | Days since the customer's most recent valid order | 45 | Lower = more recently active |
| frequency | integer | Number of valid orders placed | 6 | Purchase frequency |
| monetary | float | Total revenue from this customer | 85,400.00 | Lifetime spend |
| R_score / F_score / M_score | integer (1-5) | Quintile score for each RFM dimension | 5 / 4 / 5 | 5 = best, 1 = worst |
| RFM_score | string | Concatenated R+F+M scores | "545" | Compact segment key |
| RFM_sum | integer | Sum of the three scores | 14 | Overall value indicator |
| segment | string | One of 8 business segments (see below) | "Champions" | Marketing action |
| segment_description | string | Plain-language description of the segment | — | Stakeholder-friendly explanation |

**Segment definitions:**

| Segment | Definition |
|---|---|
| Champions | Bought recently, buy often, and spend the most |
| Loyal Customers | Consistent repeat buyers with strong spend |
| Potential Loyalists | Recent customers with moderate frequency |
| New Customers | Very recent, low-frequency (1-2 order) buyers |
| At Risk | Historically good customers who haven't purchased recently |
| Can't Lose Them | Big spenders/frequent buyers who have gone quiet |
| Hibernating | Below-average across recency, frequency, and monetary value |
| Lost | Lowest scores across all three RFM dimensions |

## customer_features

One row per **registered** customer (including those with zero valid orders), used as the base table for CLV and repeat-rate calculations.

Same columns as `customers_clean` plus: `order_count`, `total_revenue`, `total_profit`, `first_order_date`, `last_order_date`, `avg_delivery_days`, `average_order_value`, `is_repeat_customer`, `customer_tenure_days`.
